# Architecture

Infurnace runs **Qwen3.5-4B** on tinygrad's own Qwen3.5 implementation (`tinygrad.llm.model`), and
replaces its hot paths with infurnace's kernels on NVIDIA GPUs. It is a single-user application, not
a general inference engine.

## Modules

| Module | Responsibility |
|---|---|
| `cli.py` | Chat (warms up while you type), one raw prompt, the HTTP server, per-step benchmark |
| `serve.py` | tinygrad's OpenAI-compatible server with DFlash, per-request thinking and temperature |
| `loader.py` | Named models and first-use downloads, architecture checks, device dispatch, DFlash loading |
| `device.py` | Device probing; `nvidia()` (NV or CUDA) and the fast-path check |
| `gguf.py` | GGUF parsing (tinygrad's parser) and metadata |
| `tokenizer.py` | Qwen3.5 BPE, streaming decode, text-only chat formatting |
| `models/qwen35.py` | Upstream model loading, packed weights, fused layers, multirow prefill, prompt snapshots |
| `models/linear.py` | `_NVLinear`: packed projection used by both the target and the draft |
| `dflash/` | Draft model, target observation, parallel verification, adaptive drafting |
| `kernels/` | Custom tinygrad UOp kernels (below) |

## Devices

The fast path runs on NVIDIA GPUs through either of tinygrad's NVIDIA backends: `NV` (tinygrad's
own driver interface, Linux; probed first) or `CUDA` (the CUDA driver API). Both need tinygrad's
CUDA C renderer, which compiles with NVRTC from the CUDA toolkit. Without it tinygrad falls back to its
PTX renderer and infurnace runs tinygrad's generic Qwen3.5 code, which is far too slow to use.
Other devices (AMD, Metal, CPU) also run the generic code.

## Kernels

All are tinygrad UOp kernels that render as CUDA C.

| Kernel | Used for |
|---|---|
| `quant_gemv` | One-row projections: Q4_K/Q5_K/Q6_K weights against Q8 activations (`dp4a`). Projections that share an input share one quantization. |
| `quant_gemm` | 16-row projections on FP16 tensor cores (`mma.sync m16n8k16`, FP32 accumulation). Following Marlin: weights dequantize straight into fragment registers (packed `half2` math through inline CUDA, no repacking), activations are pre-permuted so each A fragment is one 16-byte load, and the next block is prefetched during the current MMAs. One kernel serves Q4_K and Q5_K (whose fifth bits join under the same FP16 trick), another Q6_K. |
| `gdn` | Recurrent (gated delta net) layers: `gdn_decode` for one row, `gdn_prefill` for 16-row prompt chunks, `gdn_chunk` for DFlash verification |
| `attention` | Attention over the active length only: split-KV partials and a merge (after vLLM's unified attention and llama.cpp's combine step). Grouped query heads, causal/non-causal, sliding windows, ring caches. |
| `sampling` | Fused Gumbel-max sampling over all rows (greedy at temperature 0) |
| `embedding` | Token embedding gathered straight from packed weights |

Weights stay packed and are rearranged once at load. Q4_K, Q5_K and Q6_K are tiled: each 16-row tile of each
256-value block is one contiguous run (2,304 bytes for Q4_K, 2,816 for Q5_K, 3,456 for Q6_K's 216-byte padded
blocks), so a 16-row tensor-core warp reads one run per block (Marlin's layout idea); the one-row kernel reads the
same layout. Qwen3.5's output head is tied to the token embedding and shares its packed storage.
Small parameters (norms, gates) are cached under `~/.cache/infurnace/params/`.

## Plain decoding

- **Prompt:** read 16 rows at a time with `quant_gemm` projections and `gdn_prefill`. Attention layers
  use tinygrad's own code for these rows. The 16-row graph is captured at warmup or for long prompts.
- **Each token:** `quant_gemv` projections, `gdn_decode` and the `attention` kernel (32-key segments).
- Upstream tinygrad still drives generation, its KV cache and its JIT.

## Prompt snapshots

Recurrent state can't be rewound, so a prompt that only partly matches the previous one would be read
from scratch. After each prompt, the recurrent and conv states (~50 MB, and the DFlash draft's position)
are copied to host memory at the prompt's last turn header. Up to 8 are kept. A new prompt resumes from
the newest snapshot it still matches, and snapshots it diverges from are dropped. When the list is full
the oldest goes, except the snapshot at the end of the last user message: Qwen's template drops earlier
replies' thinking when a new user message arrives, so that is where an agent's next message diverges.
Attention caches need no copy: they are indexed by position, and every kept snapshot is a prefix of
what they hold.

## DFlash

A block-diffusion draft proposes 15 tokens and the target verifies them in one 16-row forward. Details
in [DFlash](dflash.md).

## Numerics

- One-row projections round activations to Q8; 16-row projections round them to FP16 and accumulate
  in FP32. Neither equals tinygrad's generic math, and the two sum in different orders, so near-ties
  can flip a greedy token between paths.
- Output quality against the reference has not been measured yet ([roadmap](roadmap.md), priority 2).
- `loader.load_model(..., nv_quant=False)` (or `--no-nv-quant` in the benchmarks) runs the generic path.

# DFlash speculative decoding

`infurnace/dflash/` implements a [DFlash](https://github.com/z-lab/dflash) block-diffusion draft and
its verification in tinygrad. The draft proposes 15 tokens at once from the target's hidden features;
the target checks them in one 16-row forward and keeps the longest prefix it agrees with. Output is
the target's own: greedy output is the target's greedy choice, and sampled output follows the target's
distribution.

It turns on automatically for the named model on an NVIDIA GPU (`NV` or `CUDA`) when the draft is
available, and downloads it on first use. `--no-dflash` turns it off; `--dflash PATH` or
`INFURNACE_DFLASH_DRAFT` picks another draft file.

## A round

The parallel verifier (`dflash/parallel.py`) runs each round as a chain of captured graphs with one
readback at the end:

1. Commit the previous round's accepted rows: the recurrent layers' state is formed for exactly the
   accepted prefix from stored intermediates, with no per-row state snapshots.
2. Absorb those rows' target features into the draft's cache.
3. Draft 15 proposals after the anchor token.
4. Run the 16-row target forward: `quant_gemm` projections, `gdn_chunk` for the recurrent layers, the
   active-length `attention` kernel, and the fused sampler for every row's decision.
5. Pack the decisions and proposals into one readback.

The rejected suffix's attention rows are simply overwritten later.

On `NV`, back-to-back submissions need the pinned tinygrad fork, which reads GPPut back before ringing
the doorbell; without it the GPU can miss the last submission and the readback never completes. `CUDA`
doesn't need the fix.

On the RTX 5060 a round takes ~23 ms: target verify 15.8 ms (its matmuls 11 ms), draft 4.1 ms,
the rest ~1.6 ms. CPU and other devices use the sequential verifier, a one-row reference that checks
4 rows per round.

## Sampling

At temperature T the target scores each row by logit + T·Gumbel noise and takes the maximum (at T = 0,
plain argmax). The draft proposes greedily, so it is a one-hot distribution, and accepting a proposal
exactly when the target's own sample equals it is standard speculative sampling. One captured graph
serves every temperature: each request writes its temperature into a buffer the graph reads.

## Adaptive drafting

Drafting loses on unpredictable text. `_DraftPolicy` (`dflash/generate.py`) compares the wall time per
emitted token over the last ~20 rounds (running averages, at least 4 timed rounds after each probe)
with a measured one-row step. When drafting loses it decodes plain rows for 8 steps, doubling up to 128
while probes keep losing; until a one-row step has been timed, it falls back below 3.5 tokens per round.
During fallback the target's features keep flowing into the draft, so drafting can resume at once.

## Draft caches

The draft's last layer attends over the whole context. Its five sliding-window layers see only the
last 4,096 positions, so they keep a ring of 4,128 slots (position x at slot x % 4,128) instead of one
slot per context position: ~520 MB less at a 32k context. Restoring an older prompt snapshot after the
ring has lapped it hides the overwritten slots with a floor value instead of copying the draft cache
into every snapshot; proposals then see less history for a while, and output is unaffected.

## Measurements

RTX 5060, Qwen3.5-4B Q4_K_M with the Q4_K_M draft, block 16, October 2026:

| Workload | Plain | DFlash |
|---|---|---|
| Code, greedy, thinking off | ~110 tok/s | ~340 tok/s steady (7.7–8.3 tokens per round) |
| Prose, thinking on, greedy | ~110 tok/s | ~160 tok/s (4 tokens per round) |
| Temperature 0.6, thinking on | 110 tok/s | 1.6–2.0× plain |
| Prose, thinking off | 105 tok/s | 0.79–0.85× plain (probing cost; [roadmap](roadmap.md)) |
| Code at a 16k-token window | — | 332 tok/s |

Acceptance depends heavily on content: predictable code drafts 8–10 tokens per round, chatty thinking 3–5.

## Draft identity

- Repository: [Anbeeld/Qwen3.5-4B-DFlash-GGUF](https://huggingface.co/Anbeeld/Qwen3.5-4B-DFlash-GGUF)
- Revision: `a79bafa7f383f8627f925250f547fe1ebbc43ff6`
- File: `qwen35-4b-dflash-Q4_K_M.gguf`, 381,456,064 bytes
- SHA-256: `83586a63eab58b4ef9dd1d72de667738fcedb289e97d98d01d8df66f23df610f`

The GGUF, not the repository's stale `config.json`, defines the draft: six layers, hidden 2560,
FFN 9216, 32 query and 8 KV heads of 128, mask token 248077, block 16, five sliding-window layers then
a full-attention layer, feature taps `[2, 6, 10, 14, 18, 22, 26, 30]` (HF `hidden_states[N]`, before
target block N). Vocabulary identity and tensor shapes are checked before upload.

Attention follows the current official repository: sliding layers causal, the final full layer
non-causal. A GGUF `dflash.attention.causal` flag overrides all layers;
`DFlashDraft.from_gguf(..., legacy_noncausal=True)` reproduces older converters' all-non-causal policy.
See the [upstream audit](../benchmarks/experiments/dflash/upstream-audit.md) and the historical
[experiment reports](../benchmarks/experiments/dflash/README.md).

## Tests

CPU tests (`tests/dflash/`) cover accepted and rejected blocks, feature alignment, snapshot lifetime,
budgets and context limits, cancellation, EOS inside an accepted block, sampling distributions
(chi-square), ring caches against a full cache, and resuming from snapshots. GPU tests
(`INFURNACE_TEST_NV=1`) check the real model's output against plain decoding and the kernels against
references.
# Single-user serving and Pi

Infurnace reuses `tinygrad.llm.serve.LLMServer`: Chat Completions, SSE,
reasoning separation, tool-call parsing and usage reporting. Infurnace supplies
its bounded model adapter, tokenizer and the GGUF's embedded Jinja chat template.
There is no fallback template in server mode. Tools are executed by the client,
not the server.

```sh
pip install -e '.[server]'
infurnace --serve 8000 --max-context 32768
```

Startup warms up before listening unless `--no-warmup` is supplied.

- **DFlash:** generation uses DFlash whenever the chat would: the installed draft
  on an NVIDIA GPU (`NV` or `CUDA`), or `--dflash PATH`. `--no-dflash` serves plain decoding. One DFlash
  generator serves every request temperature, and greedy requests stay exactly
  greedy.
- **Prefix reuse:** both paths resume from the newest prompt snapshot the
  request still matches (up to 8, about 50 MB of system RAM each). A tool loop
  reads only each new tool result, and the next user message only the turns
  Qwen's template re-renders without their thinking.
- **Thinking:** `--no-thinking` sets the default for the template's
  `enable_thinking`. A request can override it for itself with
  `chat_template_kwargs: {"enable_thinking": false}` (the vLLM/sglang convention)
  or a top-level `enable_thinking`. Thinking text comes back as
  `reasoning_content`.
- **Output length:** request-level `max_tokens` or `max_completion_tokens`.

The default bind address is `127.0.0.1`. This upstream server has no authentication;
do not expose it to untrusted networks. Requests are processed serially.
Temperature is honored; other sampling and tool-choice request controls are not.
A request without a temperature (pi sends none) is decoded greedily, which Qwen
warns can repeat in thinking mode.
Tool-call deltas are emitted after generation.

## Pi

Merge into `~/.pi/agent/models.json`:

```json
{
  "providers": {
    "infurnace": {
      "baseUrl": "http://127.0.0.1:8000/v1",
      "api": "openai-completions",
      "apiKey": "local",
      "models": [{
        "id": "infurnace-qwen35",
        "name": "Infurnace Qwen3.5",
        "input": ["text"],
        "reasoning": true,
        "compat": {"thinkingFormat": "qwen-chat-template", "supportsDeveloperRole": false,
                   "supportsReasoningEffort": false},
        "contextWindow": 32768,
        "maxTokens": 8192,
        "cost": {"input": 0, "output": 0, "cacheRead": 0, "cacheWrite": 0}
      }]
    }
  }
}
```

Match `contextWindow` to the server's `--max-context`. On an 8 GB RTX 5060,
`--max-context 32768` with DFlash peaks at about 7.35 of 8.1 GB with a desktop
running; `maxTokens: 8192` leaves room for large file writes. The server accepts any
model ID as a label. With `reasoning: true` and the `qwen-chat-template`
format, Pi's thinking toggle sends `chat_template_kwargs.enable_thinking`, which
the server honors per request. With `reasoning: false`, Pi sends nothing and the
server's default applies. `supportsDeveloperRole: false` keeps Pi from sending its system prompt
as a `developer` message to a reasoning model (the server maps `developer` to `system` anyway).

Measured on an RTX 5060 8 GB (`--max-context 16384`, Pi print mode, read/edit
tools, thinking on). Agent turns after the first resume from a prompt snapshot and
read only their new tokens, at 250–380 tok/s (about 0.3–0.4 s of fixed cost per
request; see the [roadmap](roadmap.md)).

| Pi task | Plain | DFlash |
|---|---|---|
| Read a file and answer | 5.1 s | 4.1 s |
| Read and fix a function (2 tool calls) | 11.5 s | 8.9 s |

Generation in those turns ran at about 135–235 tok/s, against about 100 tok/s
for plain decoding.

Start with a harmless read-only request and check the whole tool call and result
cycle before allowing edits or shell commands.
"""Single-user HTTP serving on tinygrad's OpenAI-compatible server, with DFlash and per-request thinking."""
import io
import json
import time

from tinygrad.llm.serve import Handler, LLMServer
from tinygrad.viz.serve import TCPServerWithReuse

class ServerModel:
  """What tinygrad's server generates with: DFlash when a draft is loaded (one generator serves every
  temperature), else plain decoding, bounded by the context and closed when a client goes away."""
  def __init__(self, model, dflash=None, *, eos_token_ids: tuple[int, ...] = (), block_size: int = 16):
    self.model, self.dflash, self.eos, self.block = model, dflash, eos_token_ids, block_size
    self.max_context = model.config.context_length

  def get_start_pos(self, ids):  # only for the server's log line: the reused prefix, counting the prompt snapshot
    snapshots = getattr(self.model, 'snapshot_length', None)
    return max(self.model.transformer.get_start_pos(ids), snapshots(list(ids)) if snapshots else 0)

  def generate(self, ids, temperature=0.0):
    budget = self.max_context - len(ids)
    if self.dflash is not None:
      stream = self.dflash.stream(list(ids), max_new_tokens=budget, block_size=self.block, eos_token_ids=self.eos, temperature=temperature)
    else: stream = self.model.generate(ids, budget, temperature=temperature)
    try:
      yield from stream
    finally:
      stream.close()

class ChatTemplate:
  def __init__(self, metadata, tokenizer, enable_thinking=True):
    try:
      import jinja2
    except ImportError as exc:
      raise ValueError("HTTP serving requires Jinja2: install infurnace[server]") from exc
    source = metadata.get('tokenizer.chat_template')
    if not isinstance(source, str) or not source:
      raise ValueError("HTTP serving requires a GGUF chat template (no tool-unsafe fallback)")
    env = jinja2.Environment()
    env.filters['tojson'] = lambda obj, **kwargs: json.dumps(obj, **kwargs)
    env.globals['raise_exception'] = lambda msg: (_ for _ in ()).throw(RuntimeError(msg))
    env.globals['strftime_now'] = lambda fmt: time.strftime(fmt)
    env.globals['bos_token'] = tokenizer.decode([tokenizer.bos_id]) if tokenizer.bos_id is not None else ''
    env.globals['eos_token'] = tokenizer.decode([tokenizer.eos_id])
    self.template = env.from_string(source)
    self.enable_thinking = enable_thinking
    self.request_thinking: bool | None = None  # the current request's switch, if it sent one

  def render(self, messages, **kwargs):
    # OpenAI clients send the system prompt as `developer` to reasoning models; Qwen's template only knows `system`.
    messages = [{**m, 'role': 'system'} if isinstance(m, dict) and m.get('role') == 'developer' else m for m in messages]
    thinking = self.enable_thinking if self.request_thinking is None else self.request_thinking
    return self.template.render(messages=messages, **kwargs, enable_thinking=thinking)

def request_thinking(body) -> bool | None:
  """A request's thinking switch: `chat_template_kwargs.enable_thinking` (vLLM and sglang's convention,
  pi's qwen-chat-template format) or a top-level `enable_thinking` (pi's qwen format)."""
  if not isinstance(body, dict): return None
  kwargs = body.get('chat_template_kwargs')
  if isinstance(kwargs, dict) and isinstance(kwargs.get('enable_thinking'), bool): return kwargs['enable_thinking']
  return body['enable_thinking'] if isinstance(body.get('enable_thinking'), bool) else None

class RequestHandler(Handler):
  """tinygrad's handler, with the request's thinking switch applied while its prompt is rendered."""
  def do_POST(self):
    raw = self.rfile.read(int(self.headers.get("Content-Length", "0")))
    try: thinking = request_thinking(json.loads(raw))
    except ValueError: thinking = None
    self.rfile = io.BytesIO(raw)  # tinygrad's handler reads the body again
    template = self.server.template
    template.request_thinking = thinking
    try: super().do_POST()
    finally: template.request_thinking = None

class Server(LLMServer):
  def __init__(self, server_address: tuple, model, model_name: str, tok, template):
    self.model, self.model_name, self.tok, self.template = model, model_name, tok, template
    TCPServerWithReuse.__init__(self, server_address, RequestHandler)

def serve(model, tokenizer, port=8000, host='127.0.0.1', *, enable_thinking=True, dflash=None, block_size=16):
  template = ChatTemplate(model.metadata, tokenizer, enable_thinking)
  name = model.metadata.get('general.name') or 'infurnace'
  eos = tuple(i for i in (tokenizer.eos_id, tokenizer.eot_id) if i is not None)
  with Server((host, port), ServerModel(model, dflash, eos_token_ids=eos, block_size=block_size), name, tokenizer, template) as server:
    print(f"Serving {name} at http://{host}:{server.server_address[1]}/v1{' with DFlash' if dflash is not None else ''}", flush=True)
    server.serve_forever()
"""Multirow GQA attention over the active length (NV): split-KV partials, then a merge.

Ported from the design of vLLM's unified attention (vllm/v1/attention/ops/triton_unified_attention.py,
Apache-2.0): every query row of every grouped head that shares a KV head is packed into one block,
so each key and value is read once per KV head; each row has its own causal limit; the context is
split into fixed segments processed in parallel and merged afterwards, as llama.cpp's
flash_attn_combine_results does (ggml/src/ggml-cuda/fattn-common.cuh, MIT). Written in tinygrad UOps
with FP32 FMA math over the FP16 cache.

Only segments that hold active keys launch (with a window, only those inside it), so the cost
follows the visible length, not the allocated cache, with one captured graph for every length.
Row t (absolute position start+t) sees keys lo <= key < hi:
  causal:      hi = start+t+1                  non-causal: hi = start+rows
  window > 0:  lo = start+t-window+1, and for non-causal also hi <= start+t+window
  floor:       lo >= floor[0] (a one-element buffer, so captured graphs read its current value)
A ring cache (`ring=True`, sliding windows only) holds position x at slot x % its length, which
must be at least window + rows: it only keeps what a window can see. `store_rows` writes it.
"""
from __future__ import annotations
import functools
import inspect
import math

from tinygrad import Tensor, UOp, dtypes
from tinygrad.dtype import AddrSpace
from tinygrad.uop.ops import AxisType, KernelInfo
from infurnace.kernels.quant_gemv import warp_reduce
from infurnace.device import nvidia

TILE = 32      # keys staged per step: one per lane
SEGMENT = 256  # keys per block; segments are merged afterwards
QUERIES = 8    # packed query vectors per warp, at most
_NEG = float('-inf')
_VARIABLE_PARAM = {'param': True} if 'param' in inspect.signature(UOp.variable).parameters else {}

def _kernel_scalar(value: int | UOp) -> int | UOp:
  """A bound position as the kernel's own unbound variable (its value is passed at launch)."""
  if not isinstance(value, UOp): return value
  value = value.unbind_all()[0]
  return value.substitute({v: UOp.variable(v.expr, v.vmin, v.vmax, dtype=v.dtype, multiple_of=v.arg.multiple_of, **_VARIABLE_PARAM)
                           for v in value.toposort() if v.is_variable})

def _launch(outputs: tuple[Tensor, ...], inputs: tuple[Tensor, ...], start: int | UOp, fxn) -> tuple[Tensor, ...]:
  sources = tuple(t.uop for t in outputs + inputs)
  params = tuple(UOp.placeholder_like(s, slot=i) for i, s in enumerate(sources))
  scalars = tuple(v.cast(dtypes.int32) for v in start.toposort() if v.is_bound_var) if isinstance(start, UOp) else ()
  call = fxn(*params).call(*sources, *scalars)
  return tuple(Tensor(t.uop.after(call)) for t in outputs)

def _live(start: int | UOp, rows: int, segment: int) -> int | UOp:
  return (start + rows + segment - 1) // segment

def _first(start: int | UOp, window: int, segment: int) -> int | UOp:
  """The first segment any row can see: the window's start for the first row."""
  if not window: return 0
  lo = start - window + 1
  return (lo.maximum(0) if isinstance(lo, UOp) else max(lo, 0)) // segment

def _visible(key: UOp, start: int | UOp, row: UOp, rows: int, causal: bool, window: int) -> UOp:
  position = start + row
  hi = position + 1 if causal else start + rows
  if window and not causal: hi = hi.minimum(position + window) if isinstance(hi, UOp) else min(hi, position + window)
  visible = key < hi
  if window: visible = visible & (key >= position - window + 1)
  return visible

@functools.cache
def _partial_kernel(part: UOp, stats: UOp, q: UOp, kv: UOp, floor: UOp | None = None, *, start: int | UOp, kv_heads: int,
                    groups: int, rows: int, dim: int, causal: bool, window: int, segment: int, ring: int) -> UOp:
  queries, lanes_dim = groups * rows, dim // 32
  per = min(QUERIES, queries)  # one-row decode packs only the grouped heads
  warps = -(-queries // per)
  first = _first(start, window, segment)
  count = _live(start, rows, segment) - first
  block = UOp.range(kv_heads * count, 0, axis_type=AxisType.GLOBAL)
  warp = UOp.range(warps, 1, axis_type=AxisType.LOCAL)
  lane = UOp.range(32, -1, axis_type=AxisType.WARP)
  kv_head, part_index = block // count, block % count
  active = start + rows
  ms = [warp * per + j for j in range(per)]                 # packed query vector: group * rows + row
  valid = [m < queries for m in ms]
  heads, row_of = [kv_head * groups + m // rows for m in ms], [m % rows for m in ms]
  F32, zero, neg = dtypes.float32, UOp.const(0.0, dtypes.float32), UOp.const(_NEG, dtypes.float32)

  # Running softmax state per query (replicated across lanes) and this lane's output columns.
  state = UOp.placeholder((2 * per,), F32, slot=0, addrspace=AddrSpace.REG)    # max[j], sum[j]
  out = UOp.placeholder((per * lanes_dim,), F32, slot=1, addrspace=AddrSpace.REG)
  state = state.after(UOp.group(*(state[j].store(neg) for j in range(per)), *(state[per + j].store(zero) for j in range(per))))
  out = out.after(UOp.group(*(out[i].store(zero) for i in range(per * lanes_dim))))

  # The bound must be uniform across blocks: stop at the active length for short contexts.
  tiles = (active + TILE - 1) // TILE
  tiles = tiles.minimum(segment // TILE) if isinstance(tiles, UOp) else min(tiles, segment // TILE)
  tile = UOp.range(tiles, 2, axis_type=AxisType.LOOP)
  base = (first + part_index) * segment + tile * TILE
  # Stage the tile's keys (transposed: lanes read consecutive keys) and values (lanes read consecutive dims).
  k_tile = UOp.placeholder((dim, TILE), dtypes.float16, slot=2, addrspace=AddrSpace.LOCAL)
  v_tile = UOp.placeholder((TILE, dim), dtypes.float16, slot=3, addrspace=AddrSpace.LOCAL)
  threads, elements = warps * 32, TILE * dim
  loader = UOp.range(-(-elements // threads), 3, axis_type=AxisType.LOOP)
  element = loader * threads + warp * 32 + lane
  in_tile = element < elements
  key, column = element // dim, element % dim
  live_key = in_tile & (base + key < active)
  kv_index = ((base + key) % ring if ring else base + key).valid(live_key)
  stage = UOp.group(k_tile[column.valid(in_tile), key].store(kv[0, 0, kv_head, kv_index, column].load()),
                    v_tile[key.valid(in_tile), column].store(kv[1, 0, kv_head, kv_index, column].load())).end(loader).barrier()
  k_tile, v_tile = k_tile.after(stage), v_tile.after(stage)

  # Scores: lane = key, accumulated over the head dimension; queries broadcast from global.
  score = UOp.placeholder((per,), F32, slot=4, addrspace=AddrSpace.REG)
  score = score.after(UOp.group(*(score.after(stage)[j].store(zero) for j in range(per))))
  d = UOp.range(dim, 4, axis_type=AxisType.LOOP)
  acc, kd = score.after(d), k_tile[d, lane].load().float()
  score = score.after(UOp.group(*(acc[j].store(acc[j].load() + q[0, heads[j], row_of[j], d.valid(valid[j])].load().float() * kd)
                                  for j in range(per))).end(d))
  scale = 1 / math.sqrt(dim)
  keys = base + lane
  seen = (keys < active) & (keys >= floor[0].load().cast(keys.dtype)) if floor is not None else keys < active
  scores = [(valid[j] & seen & _visible(keys, start, row_of[j], rows, causal, window)).where(score[j].load() * scale, neg)
            for j in range(per)]

  # Online softmax: freeze this tile's coefficients before overwriting the running state.
  coef = UOp.placeholder((3 * per,), F32, slot=5, addrspace=AddrSpace.REG)      # safe new max, alpha, new max
  previous = state.after(score)
  frozen = []
  for j in range(per):
    new_max = previous[j].load().maximum(warp_reduce(scores[j], maximum=True, full_wave=True))
    safe = new_max.ne(neg).where(new_max, zero)        # all masked so far: keep exp() finite
    frozen += [coef[j].store(safe), coef[per + j].store((previous[j].load() - safe).exp()), coef[2 * per + j].store(new_max)]
  coef = coef.after(UOp.group(*frozen))
  probs = UOp.placeholder((per * warps, TILE), F32, slot=6, addrspace=AddrSpace.LOCAL)
  ps = [(scores[j] - coef[j].load()).exp() for j in range(per)]
  current = state.after(coef)
  updates = [probs[warp * per + j, lane].store(ps[j]) for j in range(per)]
  updates += [current[j].store(coef[2 * per + j].load()) for j in range(per)]
  updates += [current[per + j].store(current[per + j].load() * coef[per + j].load() + warp_reduce(ps[j], full_wave=True))
              for j in range(per)]
  rescaled = out.after(coef)
  updates += [rescaled[j * lanes_dim + i].store(rescaled[j * lanes_dim + i].load() * coef[per + j].load())
              for j in range(per) for i in range(lanes_dim)]
  settled = UOp.group(*updates).barrier()
  probs, out = probs.after(settled), out.after(settled)

  # Values: lane owns dims lane + 32*i; probabilities broadcast from shared memory.
  k = UOp.range(TILE, 5, axis_type=AxisType.LOOP)
  acc = out.after(k)
  vs = [v_tile[k, lane + 32 * i].load().float() for i in range(lanes_dim)]
  accumulated = UOp.group(*(acc[j * lanes_dim + i].store(acc[j * lanes_dim + i].load() + probs[warp * per + j, k].load() * vs[i])
                            for j in range(per) for i in range(lanes_dim))).end(k)
  # Every warp must finish with the tile before the next one is staged over it.
  done = accumulated.barrier().end(tile)
  out, state = out.after(done), state.after(done)

  stores = [part[kv_head, part_index, ms[j].valid(valid[j]), lane + 32 * i].store(out[j * lanes_dim + i].load())
            for j in range(per) for i in range(lanes_dim)]
  stores += [stats[kv_head, part_index, ms[j].valid(valid[j] & lane.eq(0)), s].store(state[s * per + j].load())
             for j in range(per) for s in range(2)]
  return UOp.group(*stores).end(block, warp, lane).sink(arg=KernelInfo(name=f"attention_partial_d{dim}", opts_to_apply=()))

@functools.cache
def _merge_kernel(out: UOp, part: UOp, stats: UOp, *, start: int | UOp, kv_heads: int, groups: int, rows: int, dim: int,
                  window: int, segment: int) -> UOp:
  queries, lanes_dim = groups * rows, dim // 32
  live = _live(start, rows, segment) - _first(start, window, segment)
  block = UOp.range(kv_heads * queries, 0, axis_type=AxisType.GLOBAL)
  lane = UOp.range(32, -1, axis_type=AxisType.WARP)
  kv_head, m = block // queries, block % queries
  F32, zero = dtypes.float32, UOp.const(0.0, dtypes.float32)
  top = UOp.placeholder((1,), F32, slot=0, addrspace=AddrSpace.REG)
  top = top.after(top[0].store(UOp.const(_NEG, F32)))
  s = UOp.range(live, 1, axis_type=AxisType.LOOP)
  top = top.after(top.after(s)[0].store(top.after(s)[0].load().maximum(stats[kv_head, s, m, 0].load())).end(s))
  total = UOp.placeholder((1 + lanes_dim,), F32, slot=1, addrspace=AddrSpace.REG)
  total = total.after(UOp.group(*(total[i].store(zero) for i in range(1 + lanes_dim))))
  s = UOp.range(live, 2, axis_type=AxisType.LOOP)
  acc = total.after(s)
  weight = (stats[kv_head, s, m, 0].load() - top[0].load()).exp()   # segments past this row's limit weigh 0
  total = total.after(UOp.group(acc[0].store(acc[0].load() + weight * stats[kv_head, s, m, 1].load()),
                                *(acc[1 + i].store(acc[1 + i].load() + weight * part[kv_head, s, m, lane + 32 * i].load())
                                  for i in range(lanes_dim))).end(s))
  head, row = kv_head * groups + m // rows, m % rows
  stores = [out[0, head, row, lane + 32 * i].store(total[1 + i].load() / total[0].load()) for i in range(lanes_dim)]
  return UOp.group(*stores).end(block, lane).sink(arg=KernelInfo(name=f"attention_merge_d{dim}", opts_to_apply=()))

def _masked(q: Tensor, kv: Tensor, start: int | UOp, causal: bool, window: int, ring: bool, floor: Tensor | None) -> Tensor:
  """Tensor-op fallback for other devices: softmax over the whole cache with each row's key range."""
  rows, capacity = q.shape[2], kv.shape[3]
  keys, position = Tensor.arange(capacity).reshape(1, capacity), Tensor.arange(rows).reshape(rows, 1) + Tensor(start)
  if ring:  # slot j holds the newest position at or below the last row's that is j modulo the length
    top = Tensor(start) + (rows - 1)
    keys = top - (top - keys + capacity) % capacity
  hi = position + 1 if causal else (position - Tensor.arange(rows).reshape(rows, 1)) + rows
  if window and not causal: hi = hi.minimum(position + window)
  visible = (keys < hi) & (keys >= 0)
  if window: visible = visible & (keys >= position - window + 1)
  if floor is not None: visible = visible & (keys >= floor.reshape(1, 1))
  mask = visible.where(0.0, float('-inf')).reshape(1, 1, rows, capacity)
  return q.float().scaled_dot_product_attention(kv[0].float(), kv[1].float(), attn_mask=mask, enable_gqa=True)

def attention(q: Tensor, kv: Tensor, start: int | UOp, *, causal: bool = True, window: int = 0, segment: int = SEGMENT,
              ring: bool = False, floor: Tensor | None = None) -> Tensor:
  """q: (1, heads, rows, dim) at positions start..start+rows-1; kv: (2, 1, kv_heads, capacity, dim) FP16
  cache already holding those rows (a ring of length capacity with `ring`). floor: optional (1,) int32
  buffer, the lowest visible key. Returns (1, heads, rows, dim) FP32. dim must be a multiple of 32.
  The fused kernels need NV (CUDA warp shuffles); other devices use plain tensor ops over the whole cache."""
  _, heads, rows, dim = q.shape
  _, _, kv_heads, capacity, kv_dim = kv.shape
  if dim != kv_dim or heads % kv_heads: raise ValueError("attention needs matching head sizes and grouped heads")
  if ring and not 0 < window <= capacity - rows: raise ValueError("a ring cache needs a window and room for it plus the rows")
  if not nvidia(q.device) or dim % 32 or kv.dtype != dtypes.float16: return _masked(q, kv, start, causal, window, ring, floor)
  # A ring's window can straddle one more segment boundary than its length spans.
  groups, segments = heads // kv_heads, -(-capacity // segment) + int(ring)
  part = Tensor.empty(kv_heads, segments, groups * rows, dim, dtype=dtypes.float32, device=q.device)
  stats = Tensor.empty(kv_heads, segments, groups * rows, 2, dtype=dtypes.float32, device=q.device)
  scalar = _kernel_scalar(start)
  part, stats = _launch((part, stats), (q.contiguous(), kv) + ((floor,) if floor is not None else ()), start, functools.partial(
    _partial_kernel, start=scalar, kv_heads=kv_heads, groups=groups, rows=rows, dim=dim, causal=causal, window=window, segment=segment,
    ring=capacity if ring else 0))
  out = Tensor.empty(1, heads, rows, dim, dtype=dtypes.float32, device=q.device)
  return _launch((out,), (part, stats), start, functools.partial(
    _merge_kernel, start=scalar, kv_heads=kv_heads, groups=groups, rows=rows, dim=dim, window=window, segment=segment))[0]

@functools.cache
def _ring_store_kernel(cache: UOp, values: UOp, *, start: int | UOp, kv_heads: int, rows: int, dim: int, length: int) -> UOp:
  i = UOp.range(2 * kv_heads * rows, 0, axis_type=AxisType.GLOBAL)
  d = UOp.range(dim, 1, axis_type=AxisType.LOCAL)
  c, h, r = i // (kv_heads * rows), (i // rows) % kv_heads, i % rows
  return cache[c, 0, h, (start + r) % length, d].store(values[c, 0, h, r, d].load()).end(i, d).sink(
    arg=KernelInfo(name=f"ring_store_d{dim}", opts_to_apply=()))

def store_rows(cache: Tensor, values: Tensor, start: int | UOp, *, ring: bool = False) -> Tensor:
  """Write values (2, 1, kv_heads, rows, dim) as positions start..start+rows-1 of cache, which then
  holds them (a ring of its length with `ring`, so the rows may wrap around its end)."""
  rows, length = values.shape[3], cache.shape[3]
  if not ring: return Tensor(cache.uop.after(cache[:, :, :, start:start + rows].uop.store(values.uop)))
  if nvidia(cache.device):
    return _launch((cache,), (values.contiguous(),), start, functools.partial(
      _ring_store_kernel, start=_kernel_scalar(start), kv_heads=cache.shape[2], rows=rows, dim=cache.shape[4], length=length))[0]
  offset = (Tensor.arange(length) - Tensor(start) % length + length) % length    # each slot's row, if < rows
  new = (offset < rows).reshape(1, 1, 1, length, 1).where(values[:, :, :, offset.clip(0, rows - 1)], cache).contiguous()
  return Tensor(cache.uop.after(cache.uop.store(new.uop)))
